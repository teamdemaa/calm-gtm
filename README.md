# Calm GTM

A GTM partner for founders building vertical SaaS.

Calm GTM turns what you know about your product and customers into a focused
strategy, a concrete action plan, the assets needed to execute it, and a weekly
rhythm that changes only when new evidence justifies it.

It works inside Codex, Claude Code, Cursor, and Windsurf. The output stays in
plain Markdown and CSV files in your project, with no dashboard or external
account required.

## Install

```sh
curl -fsSL https://calmgtm.com/install | sh
```

Then open your coding agent in the project where you want to work and tell it
what you are building.

## What it creates

```text
.calm/
  strategy.md
  action-plan.md
  weekly.md
  sources.md
  assets/
```

CSV versions are created alongside the Markdown files where a structured
tracker is useful.

## How it works

Calm GTM keeps four outputs stable over time:

1. **Strategy** for alignment, positioning, offer, and promotion.
2. **Action plan** organized into Now, Next, and Later.
3. **Assets** such as website copy, outreach messages, and useful resources.
4. **Weekly update** that records evidence, decisions, and justified changes.

The goal is not to generate a large marketing report. It is to help a founder
make the next good GTM decision and keep the reasoning easy to revisit.
